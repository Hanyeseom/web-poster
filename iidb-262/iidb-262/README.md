# iidb-262 Project

## Overview
The iidb-262 project is a responsive web application designed to showcase a collection of designer biographies and exhibition details. The project adapts its layout and styles for different devices, including desktops, tablets, and mobile phones.

## Project Structure
```
iidb-262
├── src
│   └── mid
│       ├── index.html        # Main HTML document
│       └── styles.css       # CSS styles for the project
├── package.json              # npm configuration file
└── README.md                 # Project documentation
```

## Files Description

### `src/mid/index.html`
This file serves as the main HTML document for the project. It includes the structure of the webpage and links to the `styles.css` file for styling.

### `src/mid/styles.css`
This file contains the CSS styles for the project. It utilizes media queries to ensure a responsive design that adapts to different screen sizes (desktop, tablet, and mobile).

### `package.json`
This file is the configuration file for npm. It lists the dependencies and scripts required for the project.

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Run `npm install` to install the necessary dependencies.
4. Open `src/mid/index.html` in your web browser to view the project.

## Usage Guidelines
- The project is designed to be responsive. Resize your browser window or view it on different devices to see the layout adapt.
- Modify the `styles.css` file to change the styling as needed.
- Update the `index.html` file to add or modify content.
